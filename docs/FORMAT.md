# 문제지·정답지 작성법

프로그램의 **도움말 → 문제지·정답지 작성법**(F1)에서도 같은 내용을 볼 수 있습니다.
**파일 → 템플릿 파일 만들기...**를 누르면 빈 문제지·정답지 한 쌍을 만들어 주므로, 그 파일을 메모장으로 열어 고치는 것이 가장 빠릅니다.

## 한눈에 보기

- 파일 두 개를 메모장으로 만듭니다.

  | 파일 | 역할 |
  |---|---|
  | `이름.questions.txt` | 문제지 |
  | `이름.answers.txt` | 정답지 |

- 두 파일은 **같은 폴더**에 두고 **앞부분 이름을 똑같이** 합니다. 프로그램은 문제지를 열면 정답지를 자동으로 찾습니다.
- 저장할 때 인코딩은 반드시 **UTF-8**입니다. 메모장에서는 *다른 이름으로 저장 → 인코딩: UTF-8*을 고르면 됩니다. (Windows 10 1903 이후와 Windows 11의 메모장은 기본이 UTF-8입니다.)
- **보기가 있으면 객관식, 없으면 단답형**으로 자동 판별됩니다. 유형을 따로 적지 않습니다.

## 문제지

### 예시 `biology.questions.txt`

```text
# 제목: 2학기 중간고사 생물
# 설명: 총 5문항

1. 세포 안에서 에너지를 생산하는 소기관은? [2점]
1) 핵
2) 미토콘드리아
3) 리보솜
4) 골지체

2. 광합성이 일어나는 식물 세포의 소기관 이름을 쓰시오.

3. 다음 중 산(acid)에 해당하는 것을 모두 고르시오. [3점]
1) HCl
2) NaOH
3) H2SO4
4) NH3

4. 다음 반응의 생성물을 쓰시오.
   2H2 + O2 -> ?

5. 다음 중 같은 족에 속하는 원소 쌍은?
① Na, K
② C, N
③ O, F
④ He, H
```

### 규칙

| # | 규칙 | 예 |
|---|---|---|
| 1 | `#`으로 시작하는 줄은 설명입니다. 문제로 취급하지 않습니다. `# 제목:`과 `# 설명:`은 시험 화면 위쪽에 표시됩니다. | `# 제목: 중간고사` |
| 2 | 문제는 **줄 맨 앞**에 `번호.` 뒤에 **한 칸 띄고** 시작합니다. 번호는 **1부터 빠짐없이 순서대로** 매깁니다. | `1. 문제 내용` |
| 3 | 배점은 문제 **첫 줄 끝**에 `[N점]`으로 씁니다. 없으면 1점입니다. | `3. 문제 [5점]` |
| 4 | 보기는 `1)`, `2)`, … 또는 `①`, `②`, … 로 시작하는 줄입니다. **2개 이상**이어야 하고 1)부터 순서대로 씁니다. | `1) 핵` |
| 5 | 보기가 있으면 객관식, 없으면 단답형입니다. | |
| 6 | 문제 내용이 여러 줄이면 다음 줄에 이어 씁니다. 단, 이어지는 줄이 `2. `처럼 **숫자+마침표+공백**으로 시작하면 새 문제로 읽히므로, 그런 줄은 앞에 공백을 넣어 들여씁니다. | `   2. 단계는 …` |
| 7 | 문제 사이 빈 줄은 있어도 되고 없어도 됩니다. | |
| 8 | 보기 내용이 길어 다음 줄로 이어지면, 이어지는 줄은 앞 보기에 붙습니다. | |

## 문제와 보기 안의 서식 (이탤릭, 첨자, 특수 문자)

| 쓰는 법 | 화면 | 용도 |
|---|---|---|
| `*Escherichia coli*` | *Escherichia coli* | 학명 등 이탤릭 |
| `**모두**` | **모두** | 굵게 |
| `H_{2}O`, `CO_{2}` | H₂O, CO₂ | 아래 첨자 |
| `Ca^{2+}`, `10^{-3}` | Ca²⁺, 10⁻³ | 위 첨자 |
| `\*` | * | 별표 자체 |

- `κ`, `α`, `β`, `℃`, `µ`, `₂`, `→` 같은 특수 문자는 **그대로 쓰면 됩니다**. 파일이 UTF-8이면 어떤 문자든 들어갑니다. Windows에서는 `Win + .`(이모지·기호 창) 또는 한글 자음 + `한자` 키로 입력할 수 있습니다.
- 서식 기호는 **채점할 때 제거**됩니다. 정답지에 `*E. coli*`라고 써도 응시자는 그냥 `E. coli`라고 입력하면 정답입니다. `H_{2}O`, `H₂O`, `H2O`도 모두 같은 답으로 봅니다.
- 응시자가 입력하기 어려운 문자가 정답에 있으면 정답지에 대체 표기를 `|`로 함께 적어 두세요. 예: `4: NF-κB | NF-kB | NF-kappaB`
- 짝이 맞지 않는 `*`, `_`, `^`는 그냥 글자로 표시됩니다. (`2 * 3 = 6`, `x^2`)

## 정답지

### 예시 `biology.answers.txt`

```text
# 2학기 중간고사 생물 정답
1: 2
2: 엽록체
3: 1, 3
4: 물 | H2O | 2H2O
5: ①
```

### 규칙

| # | 규칙 | 예 |
|---|---|---|
| 1 | 한 줄에 `번호: 정답` 형태로 씁니다. 문제지의 **모든 번호**가 있어야 합니다. | `1: 2` |
| 2 | 객관식은 **보기 번호**를 씁니다. `2`와 `②` 모두 됩니다. | `1: 2` |
| 3 | 정답이 여러 개인 객관식(모두 고르시오)은 **쉼표**로 구분합니다. 응시자가 고른 번호들이 정답과 **정확히 같아야** 정답이며 부분 점수는 없습니다. | `3: 1, 3` |
| 4 | 단답형은 답을 그대로 씁니다. 여러 답을 인정하려면 **`\|`**로 구분합니다. 그중 하나와 같으면 정답입니다. | `4: 물 \| H2O` |
| 5 | `#`으로 시작하는 줄은 설명입니다. | |

### 단답형은 이렇게 비교합니다

| 처리 | 예 |
|---|---|
| 앞뒤 공백 제거 | `  엽록체 ` → `엽록체` |
| 영문 대소문자 무시 | `h2o` = `H2O` |
| 서식 기호 제거 | `*E. coli*` = `E. coli`, `H_{2}O` = `H2O` |
| 전각 문자를 반각으로, 첨자 문자를 보통 숫자로 | `Ｈ２Ｏ` = `H₂O` = `H2O` |
| 연속된 공백은 하나로 | `엽록  체` = `엽록 체` |
| (설정) 띄어쓰기 무시 | 켜면 `엽록 체` = `엽록체` |

그 밖의 차이(오타, 조사, 괄호, 단위 표기 등)는 **다른 답**으로 봅니다. 인정할 표기가 여러 개라면 정답지에 `|`로 모두 적어 두세요. 예: `4: 물 | H2O | 2H2O | 물(H2O)`

## 자주 하는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| "문제 번호가 2번이어야 하는데 4번입니다" | 번호를 건너뜀 | 번호를 1부터 순서대로 |
| 문제가 안 읽힘 | `1.문제`처럼 마침표 뒤 공백이 없음 | `1. 문제` |
| 보기가 문제 내용에 붙어 보임 | 보기를 `1.`로 씀 | `1)` 또는 `①` |
| "보기가 1개뿐입니다" | 보기를 하나만 씀 | 2개 이상으로, 단답형이면 보기 삭제 |
| "정답이 없는 문제: 5번" | 정답지에 번호가 빠짐 | 모든 문제의 정답을 적기 |
| "객관식이므로 보기 번호를 쓰세요" | 객관식 정답에 글자를 씀 (`1: 미토콘드리아`) | `1: 2` |
| 한글이 깨져 보임 / 인코딩 오류 | ANSI(CP949)로 저장됨 | 메모장에서 UTF-8로 다시 저장 |
| "정답지가 없습니다" | 파일 이름 앞부분이 다름 (`a.questions.txt` / `b.answers.txt`) | 앞부분 이름을 같게 |

## 문제를 열 때 오류가 나면

파일 이름, 줄 번호, 이유가 표로 나옵니다. 메모장에서 해당 줄을 고친 뒤 다시 열면 됩니다. 메모장은 `Ctrl+G`로 줄 번호 이동, *보기 → 상태 표시줄*에서 현재 줄을 확인할 수 있습니다. 오류는 한 번에 전부 표시되므로 한 번에 고칠 수 있습니다.
