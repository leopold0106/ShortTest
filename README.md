# ShortTest

문제지와 정답지를 넣으면 **Windows 프로그램 안에서 문제를 풀고 자동으로 채점**해 주는 도구입니다.

- 객관식: 보기 번호를 고르면 채점
- 단답형: 답을 입력하면 채점
- 문제지와 정답지는 **메모장으로 쓸 수 있는 일반 텍스트 파일(UTF-8)** 두 개로 작성

## 왜 두 개의 텍스트 파일인가

| 선택 | 이유 |
|---|---|
| 일반 텍스트(`.txt`) | 메모장·VS Code 등 아무 편집기에서나 쓸 수 있고, JSON처럼 따옴표/쉼표/줄바꿈 이스케이프를 신경 쓸 필요가 없음 |
| UTF-8 | 한글이 깨지지 않음. CSV를 Excel로 열 때 생기는 인코딩 문제를 피함 |
| 문제지 / 정답지 분리 | 정답을 빼고 문제지만 다른 사람에게 전달할 수 있음. 프로그램은 두 파일을 함께 읽어 채점 |

## 문제지 형식 (`*.questions.txt`)

```text
# 제목: 2학기 중간고사 생물
# 설명: 총 10문항, 제한시간 없음

1. 세포 안에서 에너지를 생산하는 소기관은? [2점]
1) 핵
2) 미토콘드리아
3) 리보솜
4) 골지체

2. 광합성이 일어나는 식물 세포의 소기관 이름을 쓰시오.

3. 다음 중 산(acid)에 해당하는 것을 모두 고르시오. [3점]
1) HCl
2) NaOH
3) H2SO4
4) NH3

4. 다음 반응의 생성물을 쓰시오.
   2H2 + O2 -> ?
```

규칙:

1. **`#`로 시작하는 줄**은 메타데이터 또는 주석입니다. `# 제목:`, `# 설명:`은 프로그램이 화면에 표시하고, 그 외 `#` 줄은 무시합니다.
2. **문제**는 `번호.`(숫자 + 마침표 + 공백)로 시작하는 줄에서 시작합니다. 번호는 1부터 순서대로 매깁니다.
3. 문제 첫 줄 끝에 **`[N점]`**을 붙이면 배점이 됩니다. 생략하면 **1점**입니다.
4. **보기**는 `1)`, `2)`, … 로 시작하는 줄입니다. `①②③④⑤`도 허용합니다.
5. **보기가 있으면 객관식, 없으면 단답형**으로 자동 판별합니다. 따로 유형을 적을 필요가 없습니다.
6. 문제 본문은 여러 줄이어도 됩니다. 다음 `번호.` 줄이 나오기 전까지가 한 문제입니다.
7. 문제 사이의 빈 줄은 자유롭게 넣어도 됩니다.

## 정답지 형식 (`*.answers.txt`)

```text
# 2학기 중간고사 생물 정답

1: 2
2: 엽록체
3: 1, 3
4: 물 | H2O | 2H2O
```

규칙:

1. 한 줄에 `문제번호: 정답` 형태로 씁니다.
2. **객관식**은 보기 번호를 씁니다. 복수 정답(모두 고르시오)은 `1, 3`처럼 **쉼표**로 구분하며, 선택한 집합이 정확히 일치해야 정답입니다.
3. **단답형**은 답을 그대로 씁니다. 여러 답을 인정하려면 `물 | H2O`처럼 **`|`**로 구분합니다. 그중 하나와 일치하면 정답입니다.
4. 문제지에 있는 모든 번호의 정답이 있어야 하며, 없으면 프로그램이 불러올 때 오류를 표시합니다.
5. `#`로 시작하는 줄은 주석입니다.

### 단답형 채점 규칙

입력과 정답을 다음과 같이 정규화한 뒤 비교합니다.

- 앞뒤 공백 제거, 내부 연속 공백은 하나로
- 영문 대소문자 무시
- 전각/반각 문자 통일 (예: `Ｈ２Ｏ` → `H2O`)

따라서 `h2o`, ` H2O `, `Ｈ２Ｏ`는 모두 `H2O`로 인정됩니다. 띄어쓰기 자체를 무시할지(예: `엽록 체`)는 설정 옵션으로 둘 예정입니다.

## 파일 이름 규칙

같은 시험의 문제지와 정답지는 같은 이름에 접미사만 다르게 둡니다.

```text
biology_midterm.questions.txt
biology_midterm.answers.txt
```

프로그램에서 문제지를 열면 같은 폴더의 `.answers.txt`를 자동으로 찾습니다.

## 프로그램 동작 (예정)

1. 문제지 열기 → 정답지 자동 로드 → 파싱 오류가 있으면 줄 번호와 함께 표시
2. 문제를 한 문제씩 또는 한 화면에 풀기 (객관식은 번호 클릭, 단답형은 입력창)
3. 제출 시 자동 채점: 문항별 정오, 내 답 / 정답, 총점과 백분율 표시
4. 결과를 텍스트 파일로 저장

## 개발 상태

형식만 확정된 초기 단계입니다. 기술 스택(예: Python + tkinter/PySide, C# WinForms/WPF)은 아직 정하지 않았습니다.
